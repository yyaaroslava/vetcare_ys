


**VetCare** — це вебзастосунок для автоматизації процесів обліку, планування та моніторингу діяльності ветеринарної клініки. Проєкт розроблено як розподілену клієнт-серверну систему з розмежуванням ролей доступу, інтегрованим календарем вакцинації, електронними медичними картками пацієнтів та автоматизованим CI/CD конвеєром.

---

## Ключовий функціонал системи

Система адаптується під кожного користувача та пропонує три персоналізовані кабінети:

### Клієнт (власник тварини):
* реєстрація та авторизація в системі
* створення профілів своїх тварин (цифрова медична картка)
* запис на прийом — вибір тварини, лікаря, дати та часу, опис причини звернення
* скасування раніше зарезервованого прийому
* перегляд журналу вакцинацій своїх тварин
* перегляд історії візитів
* редагування власних персональних даних

### Ветеринарний лікар:
* перегляд та редагування медичних карток усіх пацієнтів
* управління власним розкладом і статусами прийомів
* ведення протоколу огляду (скарги, діагноз, призначення)
* внесення записів про проведені вакцинації
* планування дати ревакцинації 

### Адміністратор:
* реєстрація нових користувачів
* управління обліковими записами — перегляд, редагування, зміна прав доступу
* доступ до повної бази клієнтів та пацієнтів клініки

## Технологічний стек

Система реалізована на базі сучасних індустріальних стандартів розробки:

*   **Backend:** Python 3.11, фреймворк Django 4.2, Django REST Framework (DRF) для побудови RESTful API, автентифікація на базі JWT-токенів.
*   **Database:** PostgreSQL 15 (реляційна база даних з підтримкою транзакційної цілісності даних).
*   **Frontend:** React 18, Axios (HTTP-клієнт з інтегрованими перехоплювачами для автоматичного оновлення JWT-токенів), адаптивна верстка на базі кастомних CSS-змінних (HSL).
*   **DevOps / DevOps:** Docker & Docker Compose (контейнеризація всіх сервісів), Nginx (вебсервер для статичного фронтенду та проксі-сервер для API), GitHub Actions (автоматичне модульне тестування та безшовний деплой на хмару Render via Deploy Hook).

##  Швидкий старт (Локальний запуск)

Для розгортання всього проєкту локально вам знадобиться лише встановлений **Docker** та **Docker Compose**.

### 1. Клонування репозиторію
```bash
git clone https://github.com/yyaaroslava/vetcare_ys.git
cd vetcare_ys
```

### 2. Запуск контейнерів
Запустіть оркестрацію мультиконтейнерного середовища однією командою:
```bash
docker-compose up --build
```
*Ця команда автоматично скачає образи, змонтує бази даних, проведе міграції, наповнить базу тестовими демо-даними та запустить сервер Django разом із React-клієнтом.*

### 3. Доступ до платформи
Після запуску контейнерів сервіси стануть доступні за такими адресами:
*   **Клієнтський React SPA інтерфейс:** [http://localhost](http://localhost) (порт 80)
*   **Серверний REST API бекенд:** [http://localhost:8000/api/](http://localhost:8000/api/)
*   **Адміністративна панель Django:** [http://localhost:8000/admin/](http://localhost:8000/admin/)

## CI/CD Автоматизація

Кожна зміна у гілках `main`, `feature/*` та `fix/*` автоматично перевіряється конвеєром на базі **GitHub Actions**:
1.  **Build:** Ініціалізація контейнерів Python та Node.js.
2.  **Test:** Запуск автоматичних модульних тестів бекенду (`manage.py test`) та перевірка збірки фронтенду.
3.  **Deploy:** При злитті в гілку `main` автоматично надсилається вебхук-тригер (Deploy Hook) на платформу **Render**, що запускає безшовне оновлення робочої версії застосунку без зупинки сервісів.
