# VetCare - Система управління ветеринарною клінікою

Вебзастосунок для автоматизації процесів ветеринарної клініки.

## Технологічний стек
- **Backend:** Django 4.2
- **Frontend:** React 18
- **Database:** PostgreSQL

## Структура проєкту
- `backend/` — серверна частина (Django)
  - `core/` — налаштування проекту
  - `apps/` — модулі системи (accounts, animals, appointments, vaccinations, visits)
- `frontend/` — клієнтська частина (React)
